# Personal Agent Harness v2.0.0

The first stable Harness V2 release packages 18 public Skills for Codex, Claude Code, and other providers supported by the open `skills` CLI.

## Highlights

- Seven Harness V2 Core Skills cover project setup, idea exploration, goal design, execution, diagnosis, close, and maintenance.
- Brownfield repositories receive read-only discovery, source-of-truth authority analysis, thin router and `TESTING.md` proposals, and explicit tracked/local-only path policy before mutation.
- Approved brownfield apply is bound to the reviewed plan digest and uses precondition revalidation, path-scoped approval, recoverable transactions, rollback, recovery, idempotency, and fault-injection coverage.
- Self-containment validation, read-only pilots, and local/remote installation evidence are bound to verified Git commit and tree identities.
- Replaced workflow Skills remain non-discoverable under `legacy-skills/`.

## Installation

List or install Skills interactively:

```powershell
npx skills@latest add https://github.com/young-sub/Skill_Management/tree/v2.0.0 --list
npx skills@latest add https://github.com/young-sub/Skill_Management/tree/v2.0.0
```

See the repository `README.md` for provider-selective installation, prerequisites, updates, uninstall, and installed bootstrap helper paths.

## Verification

- Full Python unit and contract suite.
- Generated resource drift and distribution validation.
- Three isolated Harness V2 pilots.
- Local-source install/refresh and remote GitHub install/update smoke tests across Codex and Claude Code.
- Independent Work Packet reviews for brownfield discovery, safe apply, and evidence hardening.

The durable evidence is recorded under `distribution/evidence/`, `docs/pilots/`, and the completed Work Packets.
