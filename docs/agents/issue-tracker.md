# Tracker Integration

Local ephemeral work lives under `.work/goals/`. Repository configuration may optionally map an external Issue/PR tracker, but publication is a separate human-triggered action. The Git code channel is independent from tracker access.

Do not create tracked Work Packet archives for ordinary Goals. Durable release, legal, regulatory, or audit records are opt-in documents with an explicit owner and retention requirement. Never infer push, PR publication, merge, or close authority from local completion.
