## PRD summary

The Harness V2 distribution must expose only intended, self-contained skills and support reproducible selection/install flows for Codex and Claude Code. WP-01 establishes those boundaries and evidence without implementing runtime workflow behavior.

## Vertical slices

1. Inventory and validate the intended public skill catalog while excluding preserved legacy workflow skills.
2. Establish canonical authoring resources and deterministic synchronization with source hashes.
3. Verify local catalog discovery and isolated provider installation behavior.
4. Document installation and repository routing from verified behavior.

## Acceptance criteria

- Every public skill directory matches its frontmatter `name` and uses only allowed frontmatter fields.
- Public skills have no repository-external or cross-skill runtime resource dependencies.
- Replaced workflow skills are preserved but not discoverable as public `SKILL.md` entries.
- Generated resources match canonical authoring sources by recorded hash.
- `npx skills add . --list` exposes exactly the intended public catalog.
- Isolated Codex and Claude Code target installation succeeds when supported by the installed CLI.
- Root `AGENTS.md` and `CLAUDE.md` are byte-identical and under 100 lines.
- README documents verified interactive, non-interactive, update, uninstall, and project setup flows.
