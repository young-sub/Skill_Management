# B4 실제 실행과 최종 제안 — 2026-10-18

**최종 검토본은 [B4 기반 전역 제안](global-agent-instructions-proposal.md)이다. 운영 반영은 하지 않았다.** B1의 12개 원칙 중 3개를 다듬어 작업 규모와 필요한 근거를 구분하고, 실행 상태에 따른 장애 대응과 충분한 확인 후 종료를 명확히 했다. [사전 개정안·판정 기준](global-guidance-b4-proposal.md)을 따라 실험했다. B4를 선택한 이유는 이 판단 기준의 명료성이며, A보다 성능이 좋다는 실험 결론이 아니다.

독립 부모 평가에서는 네 구현 모두 HTTP·Domain·SQLite·프로세스 종료 15개 관찰을 통과했다. 후보가 직접 HTTP 응답을 확인한 것은 안내 조건의 두 세션뿐이다. 기존 CSS와 사용자 메모는 네 번 모두 보존됐고, 설치·provider·운영 전역 변경이나 과제 중 부모 수리는 없었다. 명시적인 SKILL.md 본문 읽기는 없었다.

안내 조건의 후보 보고서에는 `ready: true, service: Inventory, storage: sqlite, item_count: 0`가 실제 서비스 시작 관찰로 남았다. 이후 browser_drive는 Chromium spawn EPERM으로 막혔고 소유 서비스는 정리됐다. 이번 요청은 /health 변경이므로 API 관찰 완료와 브라우저 전체 미확인을 구분했다. 전체 제품 흐름 PASS로 집계하지 않는다.

## 비교 조건과 한계

처음 자율 발견 쌍은 무효 비교다. 실제 스킬 목록이 A 48개, B4 39개로 달랐다. 구성 파일이 같아도 원격 플러그인 노출이 달라졌으며, 이 결과로 지침 효과나 성능 우열을 판정하지 않았다. 실패와 비용은 목록에 유지했다.

이 차이를 확인한 뒤 모델 호출을 멈추고 로컬 CLI 0.160.0의 생성 프로토콜을 조사했다. TurnStartParams의 `disabledPluginIds`는 해당 thread의 제외 목록을 설정한다. 읽기 전용 plugin/list로 식별자를 확인한 뒤 남은 안내 쌍에만 github, openai-templates, pages, plugin-management, sites, work-pets의 openai-curated-remote ID를 동일하게 제외했다. 설치본·운영 설정을 바꾸거나 안전·권한 검사를 제거하지 않았다. task-local 실행기에 선택적 요청 필드 한 개를 추가했고 diff를 보존했다.

안내 쌍은 실제 스킬 안내가 모두 39개였으며 cwd와 전역 본문, CR 줄바꿈을 정규화하면 user/developer 메시지가 일치했다. 전역 원문과 실제 모델/추론도 확인했다. 따라서 **안내 조건 내부 A/B4 비교만 유효**하다. 안내 전후에는 플러그인 선택 조건도 바뀌었으므로 성공을 안내 하나의 인과 효과로 확정할 수 없다. 현재 운영 0.1.76·Ponytail 조합에도 일반화하지 않는다.

## 최종 판단

- B4는 안내된 경로에서 실제 관찰을 완료하고 사용자 변경·권한·작업 범위를 보존했다. 이 제한된 경로의 호환성 근거는 확보했다.
- A도 같은 경로에서 성공했다. 전역 지침 강화가 성공 원인이라는 주장은 하지 않는다. B4의 시간·토큰 우위도 일관되지 않았다.
- 자율적인 실행 경로 발견 개선은 입증되지 않았다. 다음 운영 개선은 기존 실행법과 보고서의 목적별 관찰 위치를 프로젝트 진입점에 연결하고, 새 명령 작성 없이 재사용할 수 있게 하는 것이다. 이번에는 프로젝트·설치 스킬을 개편하지 않았다.
- 전역 문서 정비와 완료율 개선의 판단을 분리한다. B4는 간결한 검토용 최종안으로 남기되, 무도움 완결성의 해결책이나 일반적인 품질 향상으로 홍보하지 않는다. 추가 실패마다 전역 조항을 늘리지 않는다.

최종 제안은 실험한 B4와 같은 LF 바이트이며 SHA256은 `bf960f552a46b3e80b0061e230a1fc3e0362d0c48ad093908da505b4b53c6923`이다. 운영 반영이 승인되면 [전역 개정 절차](../agents/global-guidance.md)의 현재 파일 재확인·백업·동시 반영을 별도로 수행한다. 그 전까지 운영 A는 유지한다.

## 비용·보존

승인된 4세션을 모두 실행했고 추가 모델 호출은 하지 않았다. 합계 97.842초, 입력 522,626(캐시 456,448), 출력 4,314이며 reasoning 781은 출력에 포함된다. 비캐시 입력은 66,178이다. 금액과 환경 준비 전체 시간은 unknown이다. 승인 한도 내에서 종료했다.

원시 자료는 `.work/global-guidance-b4-20261018/`에 보존한다. `run-ledger.json`, `budget-final.json`, `condition-comparison.json`, 실제 세션·도구 기록, 네 프로젝트 ZIP·diff·파일 해시, 후보 보고서, 독립 oracle, 이전 최종 B1과 A/B4 diff를 포함한다. `preparation/context-drift.diff`와 `guided-condition-amendment.json`에 비교 무효 원인과 조건 변경을 남겼다. 과거 자료는 덮어쓰지 않았다. 운영 전역 해시와 테스트 홈 설정 복원을 확인했다.

변경 범위는 documentation이다. B4 검토본을 갱신하고 결과를 연결했으며 제품·플러그인 구현, 전역 설치, 관련 없는 readiness 상태, push는 변경하지 않았다.
