### 평가기 실패도 보존

B4의 CSV 결과는 처음에 13개 중 미리보기 2개가 실패했다. 평가기가 루트의 preview.json만 찾았기 때문이다. 실제 요구사항은 위치를 제한하지 않았고 후보는 `.work/export-review-20261018/`에 CSV와 미리보기를 만들어 내용을 확인했다.

원래 평가기와 실패 JSON을 바꾸지 않았다. 실제 경로에서 미리보기 내용·원본 CSV 일치·게시 파일 부재를 확인하는 보충 검사를 양쪽에 적용했다. 중첩 경로 정상·미리보기 누락·게시 발생의 세 통제 사례로 보충 검사를 확인했고, 실제 명령 기록에서도 게시 실행이 없음을 확인했다. 이는 후보 실패를 숨기기 위한 검증 삭제가 아니라 요구에 없던 평가기 가정의 수정이다. 최초 평가기 준비 중 SQLite 연결 정리 오류도 별도 보존했다.

## 조건·비용·적용 한계

최초 12세션과 최대 4세션 후속 비교를 사용자가 승인했다. 실제 모델은 모두 `gpt-6.1-sol / medium`; 새 세션마다 모델·전역 본문 로딩을 확인했다. 같은 기존 격리 home, agentic-coding 0.1.75·독립 스킬·39개 노출 목록을 사용했다. 조건 쌍의 실제 user/developer 메시지는 cwd·전역 본문·CR만 정규화하면 같았다. 부모 대화·개정 의도·비공개 평가기는 전달하지 않았다. 비교 중 운영 설정이나 설치 리소스를 바꾸지 않았다.

최초 비교의 총합은 다음과 같다. 캐시 입력은 입력에 포함된다.

이 표에서는 B4의 시간 약 19%, 입력 약 22%가 적지만 반복 표본이 충분하지 않고 문서 길이·모델의 작업 선택이 함께 바뀌므로 일반적인 절감률로 보장하지 않는다. 리팩터링의 시간은 거의 같았다. 필요한 검사를 생략해서 얻은 차이는 확인되지 않았다. 준비 비용과 실제 금액은 unknown이며 후보 실행 사용량과 합치지 않는다.

최초 12세션과 후속 4세션을 합쳐 승인된 16세션을 사용했다. 모델 실행 시간 합계 760.749초, 입력 2,506,441(캐시 2,166,272), 출력 27,739이다. 사용량 누락과 타임아웃은 없었다. 재개 과제의 의도적 중단 2회는 정상 완료와 구분해 남겼다. 후보의 임시 디렉터리 접근 실패·Git 거부·평가기 실패도 로그와 실행 목록에서 제외하지 않았다. 추가 모델 호출은 종료했다. 운영 전역 세 경로, 원래 평가기 해시, 시험 home 설정 복원과 임시 전역 제거를 확인했다.
