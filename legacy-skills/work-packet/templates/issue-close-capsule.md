# Issue Close Capsule

Use this template for GitHub Issue close comments. Keep detailed implementation
evidence in the PR body, tracked archive, or durable verification capsule.

```text
Closed by: <PR URL>
Outcome: <one-line delivered behavior>
Verification: <summary plus PR/body/archive/capsule pointer>
Remaining risk: <none or one-line risk>
Next: <next issue or explicit none>
```
