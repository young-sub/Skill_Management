# HWP form fill

기본 완료 결과는 **원본과 분리된, 내용과 구조가 검증된 HWPX**다. HWP와 검수용 PDF/이미지는 선택 결과다. HWP 미지원·변환 실패 때문에 유효한 HWPX를 폐기하거나 전체 작업을 실패로 처리하지 않는다. 구조 검사와 실제 페이지 배치 검수를 구별해 보고한다.

## 시작과 도구 선택

- 최초 설치·환경 문제는 [setup.md](references/setup.md), 실제 작성은 [workflow.md](references/workflow.md)를 읽는다.
- `python scripts/doctor.py`로 현재 인터프리터를 검사한다. 한컴 실제 검사는 `--smoke-test`일 때만 한다. COM 등록만으로 변환 성공을 주장하지 않는다.
- 설치된 `hwpx` 스킬과 해당 작업 참조를 먼저 확인한다. **플러그인 폴더 존재는 MCP 연결 증거가 아니다.** 현재 세션 도구 목록에서 실제 노출을 확인하고 노출된 `mcp_server_health` 및 `describe_capabilities`를 호출한다. 정상이라면 MCP를 우선한다. 스키마는 설치된 generated contract를 따른다.
- MCP가 없거나 정상 작동하지 않으면 로컬 `python-hwpx`를 사용한다. 기존 프로젝트 가상환경을 먼저 확인한다. 서버 설정 변경이나 설치 반복으로 문서 작업을 중단하지 않는다. Python 진단기는 호스트 도구 노출을 판정할 수 없으므로 에이전트가 확인 결과를 별도 보고한다.
- 기존 엔진의 분석·채움·검증 기능을 재사용한다. 범용 양식 엔진, XML 직접 편집기, 변환 서비스를 새로 만들지 않는다. 문서는 외부 웹/클라우드 변환기로 업로드하지 않는다. 렌더 MCP도 외부 전송 없는 로컬 처리인지 확인한다.

## 공통 순서

1. 입력을 원본 양식, 참고 자료/데이터, 사용자 직접 값, 결과 경로로 구분한다. 기준일/기간과 보존할 요소도 확인한다.
2. 원본과 다른 새 결과 경로를 정하고 원본 SHA256을 **편집 전에** 기록한다. 기존 결과·정답 예시도 덮어쓰지 않는다.
3. 문단·표·논리 행/열·병합 anchor·누름틀·본문 placeholder·빈 영역·예시 페이지·작성 안내·샘플 값·로고/이미지·머리글/바닥글·숨은 빈 문단·페이지 나눔을 분석한다.
4. 참고 자료에서 사실을 추출한다. 사실과 요약/해석을 구별한다. 내부 매핑은 `양식 항목 → 입력값 → 근거 문서/위치 → 요약·형식 변환 → 확정 여부 → 적용·검증 방법`이다.
5. 유일하고 명확한 값은 적용한다. 결과를 실질적으로 바꾸는 누락·충돌·대상 모호성만 묶어 질문한다. 근거 없는 날짜·담당자·진척률·상태·금액·승인·기관명을 만들지 않는다.
6. 병합 표는 **논리 좌표와 anchor**로 처리한다. 서식과 병합 구조를 보존한다. 예시·안내·샘플·잘못된 로고는 실제 작성 영역과 명확히 구분되고 보존 지시와 충돌하지 않을 때만 제거한다.
7. 새 HWPX에 저장하고 ZIP/XML/필수 part/open-safety/재열기/기대 문자열/금지 문자열/원본 해시를 검증한다. 전체 필수 항목의 정확한 대상 값도 다시 읽어 비교한다.
8. Windows·한컴 COM·pywin32가 준비되면 실제 Open/SaveAs로 선택적 HWP를 만든다. 기본 `auto`, 요청 시 `off` 또는 명시적 필수 조건에만 `required`를 쓴다. 실제 바이너리 OLE 시그니처와 한컴 재열기를 확인한다.
9. 사용 가능한 로컬 렌더러가 있으면 모든 페이지를 렌더하고 **이미지를 실제로 열어** 시각 검수한다. 렌더 성공만으로 시각 검수 완료를 선언하지 않는다.
10. 결과 경로, 기본 검증, 원본 보존, 시각 검수 범위, HWP 상태와 생략 이유를 보고한다. 렌더러가 없으면 구조·내용 검증까지만 완료했다고 명시한다.

## 실행 도우미

스킬 디렉터리 기준:

```text
python scripts/doctor.py
python scripts/doctor.py --smoke-test
python scripts/convert_and_validate.py <결과.hwpx> --hwp auto --expect <필수문구> --forbid <제거문구> --source <원본.hwpx> --source-sha256 <편집전해시> --output-dir <새출력폴더> --pdf --render-dir <새이미지폴더>
```

검증기는 HWPX를 채우거나 수정하지 않는다. 작성은 기존 엔진과 에이전트의 근거 판단이 담당한다. `--format json`은 JSON만, 기본값은 표와 JSON 모두 출력한다. 정상 HWPX에서 `auto`의 HWP 실패는 성공 종료와 `HWP 변환: SKIP`으로 남긴다. `required`만 HWP 실패를 비정상 종료로 바꾼다. 미지정 내용 조건/원본 해시는 SKIP이므로 이를 스킬 완료 검사로 오인하지 않는다.
